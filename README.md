# Mangalore Atlas 🌴

A hand-built, low-poly 3D world of Mangalore (Kudla) — inspired by [levels.fyi/atlas](https://www.levels.fyi/atlas).

**60+ landmarks** with stylized 3D models: temples (Kadri with its ponds & hilltop Shiva, Kudroli's gopuram, Kateel on its river islet), beaches with kites & watersports, the hilltop airport, NITK, hospitals, malls, ice-cream parlours, and the city's IT buildings. Real geography — coastline, the Gurupura & Netravati rivers, the Bengre spit, real elevations — plus living details: rampaging private buses on NH-66, the Tannirbhavi ferry, a circling plane, ships heading to NMPT.

## Features
- 📖 **Story Mode** — "A Day in Kudla", a 14-chapter cinematic tour
- 🧳 **Trip planner** — build an itinerary and tour it stop by stop
- 🔍 Search, category filters, fun facts on every landmark

## Run
It's a single `index.html` — open it, or:

```bash
python3 -m http.server 8734
# → http://localhost:8734
```
